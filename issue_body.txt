## Descripción

Configurar el sistema para soportar múltiples negocios con diferentes plantillas y unidades de medida.

## Negocios requeridos

### 1. Business ID 1:
- Tipo: POS (Service Store VIP)
- Unidad: unidades
- Flujo: ventas tradicional

### 2. Business ID 2:
- Tipo: deshidratados
- Unidad: kg
- Flujo: producción simplificada

## Objetivos

- Detectar el negocio activo al iniciar
- Cargar automáticamente su plantilla
- Adaptar la UI según el tipo de negocio

## Implementación sugerida

### 1. Agregar campo 'tipo' a negocios:
\`\`\`typescript
interface Business {
  id?: number
  name: string
  tipo: 'pos' | 'deshidratados'
}
\`\`\`

### 2. Crear configuración por tipo:
\`\`\`typescript
const businessTemplates = {
  pos: {
    unidad: 'unidades',
    showProduccion: true,
    showGastos: true
  },
  deshidratados: {
    unidad: 'kg',
    showProduccion: true,
    showGastos: false
  }
}
\`\`\`
